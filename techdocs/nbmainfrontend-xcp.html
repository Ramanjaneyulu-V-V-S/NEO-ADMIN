01 Project Overview

The NABARD Modern UI is the end-user frontend for the xCP Case Management System. Built with React 19, Redux Toolkit, and Kendo React, it provides case management, Digidak correspondence, document viewing via OpenText Brava, and dashboard analytics — all connected to the xCP backend through REST APIs.

03 Pages & Views

Dashboard

Main landing page after login. Displays case statistics (Chart.js), recent cases grid, Digidak metrics, and user greeting. Sub-components: caseList/, ecmChart/, digidakChart/, digidakList/, userGreeting/.

Case Management

PageKey Features
Inbox3 tabs (FYA, EA Tasks, To Be Verified); Kendo Grid with filters; Acquire, Push Back, Movement Register actions
Create CaseFile number selection, notesheet via inline editor, document upload, vertical/department selection
View Case (1473 lines)6 tabs: Info, Documents, Notesheet, Workflow, Comments, Reference Cases. Split Brava Viewer. Approve/Reject/Send/Cancel/Close actions
OutboxSent cases grid with status tracking
Search CaseDQL-based search via cms_full_text_search
Old CasesLegacy case archive browser

Digidak (Correspondence)

PageKey Features
Inward EntryRegister incoming letter: sender, category, priority, secrecy, language, doc upload, permission assignment
Outward EntryNature selection (internal/external), multi-select recipients, endorsement sequence, doc management
Draft EntrySave-as-draft, retrieve and resume editing
Inbox / OutboxFiltered grids, action buttons, read/unread status
View EntryFull letter detail with Brava Viewer integration
ForwardForward correspondence to additional recipients

Login & Auth

Login page with username/password + captcha validation. Caps Lock detection. Credentials base64-encoded as Token in localStorage. 30-minute session timeout with 1-minute warning modal.
